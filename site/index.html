How to generate and download

  1. Upload exactly one .ipa file as an asset on a GitHub Release. For private apps, make this repository private first; release assets in a public repository can be public.
  2. For signing, add APPLE_CERTIFICATE_BASE64, APPLE_CERTIFICATE_PASSWORD, and APPLE_PROFILE_BASE64 under repository Settings → Secrets and variables → Actions. Do not put secrets in source files.
  3. Open the workflow using either button, tap Run workflow, and enter the release tag.
  4. When the run finishes, open the run summary and download the omnisette-server-package and signed-ipa artifacts. The IPA job can only succeed if the certificate, profile, bundle ID, and app structure match.

GitHub Pages is a static website: it cannot run Docker itself or securely accept Apple credentials. Build jobs run on GitHub Actions. A generated server package is downloadable but does not create a permanent Linux server; deploy it to a Linux host you control if you need a persistent endpoint.
